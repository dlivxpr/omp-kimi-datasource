# Triage Labels

技能使用五个 canonical triage role。本文件将这些 role 映射到本仓库 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库 tracker 中的标签 | 含义 |
| -------------------------- | ---------------------- | ---- |
| `needs-triage` | `needs-triage` | Maintainer 需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已充分说明，可交给 AFK agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个 role（例如 "apply the AFK-ready triage label"）时，使用上表中对应的本仓库标签字符串。

如需匹配现有标签词汇，请编辑右侧列。
